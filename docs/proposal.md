# 机器人集群控制系统 — 项目立项必要性说明

> 版本：2026-08 ｜ 用途：公司内部立项评审
> 配套文档：`docs/architecture.md`（系统整体架构）

---

## 一、立项背景：厂商生态的真实空白

### 1.1 现状

智元（AgiBot）作为人形机器人厂商，当前面向使用者提供的操控软件形态为：**官方 SDK（面向开发者）+ 手机端 App（面向使用者）**，**没有桌面端（PC/Mac）管理软件**。

### 1.2 手机端在实际业务中的局限

以我们的交付场景（展厅迎宾、导览接待、多机表演、批量交付运维）实测：

| 痛点 | 具体表现 |
|---|---|
| **多机编排无法开展** | 编排（多机器人按时间线协同表演）是机器人展示的核心价值。手机屏幕小，时间线多轨道在手机上基本无法查看与编辑，"两台机器人配合说话+动作"这类最基础的编排在手机上操作极其困难 |
| **单机视角，无集群管理** | 手机 App 以单台机器人为中心，无法一屏总览全部设备状态、无法批量操作（如固件升级要逐台处理） |
| **演示与交付形象受限** | 商务演示时手机小屏操作专业感和可信度不足 |
| **数据无法沉淀** | 编排内容、地图、媒体资产分散在手机/机器人上，换手机即丢失，无法团队共享 |
| **运维效率低** | 批量装机、版本升级、故障排查缺工具支撑，交付 N 台机器的运维成本随台数线性上涨 |

### 1.3 结论

**"桌面端集群管理系统"是智元生态当前明确的能力空白**，而这个空白恰好卡在我们实际业务（多机交付、编排表演、批量运维）的咽喉上。谁先补上这个空白，谁就在人形机器人的落地交付环节建立了不可替代的效率与体验优势。

## 二、系统已具备的能力（可行性已验证）

本项目**不是从零开始的概念方案**——v2.1.0 已开发完成并在实机（智元 X2）上验证运行。已实现：

### 2.1 全生命周期管理

- **一键装机**：输入机器人 IP 和密码，自动完成 agent 安装、开机自启、配对（全程约 1 分钟，传统手工部署约 30 分钟）
- **批量固件升级**：多台机器人并发更新、进度可视、失败保留旧版本、更新前机器人语音播报提醒
- **设备总览**：一屏查看全部机器人在线状态、电量、Agent 版本

### 2.2 专业操控（桌面级体验）

- 八大操控面板：仪表盘 / 遥控 / 相机 / 语音 / 表情 / 媒体 / 灵创动作 / 系统
- 快捷遥控小窗（键盘 WASD 操控、速度档位、多窗口并行）
- 相机实时画面 + 一键拍照存档

### 2.3 多机编排（本系统的核心差异化）

- **剪映式时间轨道编辑器**：每台机器人一条轨道，任务块拖拽编辑——把"编舞"门槛从写代码降到会用剪辑软件
- 语音自动配动手势（边说边比划）、精确到秒的多机同步
- **三方能力扩展**：任意 HTTP 接口（门禁、灯光、企业微信通知等物联网设备）配置后即可作为编排步骤——机器人表演与展馆环境联动

### 2.4 地图与自主能力

- **建图工作台**：遥控建图时实时显示激光点云（墙体轮廓随行走生长）+ 行走轨迹——解决"扫图时不知道扫没扫全"的行业普遍痛点
- 地图管理、重定位

### 2.5 本地语音转写（全离线）

- 内置轻量模型装完即用，高精模型一键下载；机器人语音片段自动转文字
- 为下一步"语音对话/语音指令"奠基

### 2.6 其他

3D 展馆（数字孪生雏形）、自由控制按钮墙、日/夜主题、中文全量界面。

> **以上全部功能已在实机验证运行，安装包与机器人固件均可一键产出。**

## 三、持续开发的路线图（立项后做什么）

### 3.1 短期（1-3 个月）：智能交互闭环

| 方向 | 价值 |
|---|---|
| **语音对话闭环**（ASR 已就绪 + 大模型 API + TTS 已有） | 机器人从"遥控工具"变"可对话的智能体"——所有演示场景的引爆点 |
| **人体跟随** | 迎宾导览刚需：识别人员并保持距离跟随，相机与控制链路已全部打通 |
| **手势识别** | 挥手/比心触发动作，交互演示效果强 |

### 3.2 中期（3-6 个月）：自主作业

| 方向 | 价值 |
|---|---|
| **定点导览**（SDK 导航能力开放后） | 编排 + 地图导航点联动 = 展馆全自动导览闭环（迎宾→带路→讲解→返回） |
| **巡逻安防** | 定时巡航 + 拍照 + 异常识别，开辟安防业务线 |
| **数字孪生** | 3D 展馆实时镜像真机姿态，监控与演示双用 |

### 3.3 长期（6 个月+）：数据与生态

| 方向 | 价值 |
|---|---|
| **多型号接入**（A2/A3/机器狗） | 能力契约架构保证新型号零界面适配——集群规模化的技术护城河 |
| **遥操作数据采集** | 对接智元开源数据生态（AgiBot World），遥控过程全量记录导出为训练数据——从"使用工具"升级为"数据资产生产线" |

## 四、业务价值量化

| 维度 | 现状（无系统） | 使用本系统 |
|---|---|---|
| 单台部署 | ~30 分钟手工操作 | ~1 分钟一键装机 |
| 批量升级（10 台） | 逐台 SSH，约 1 小时 | 一次操作并发完成，约 5 分钟 |
| 多机编排制作 | 无工具，需写代码 | 剪映式编辑，非技术人员可上手 |
| 建图确认 | 盲扫，扫完才知道结果 | 实时点云可视化，边扫边看 |
| 演示形象 | 手机小屏 | 专业桌面软件 + 3D 展示 |

**边际成本极低**：系统一次开发，每交付一个项目直接复用（装机→编排→交付全流程工具化），且积累的编排/地图/媒体资产可在项目间复用。

## 五、风险与对策

| 风险 | 评估与对策 |
|---|---|
| 依赖智元 SDK 开放程度 | 架构上 agent 层隔离了 SDK 变化（1.0→2.0 已平滑演进一次）；SDK 未开放的能力（如导航到点）已验证绕行/等待策略 |
| 厂商推出官方桌面端 | **非风险，反为合作机遇**（详见图 1 定位）：本系统定位多机集群与交付集成，与厂商单机终端产品互补；作为智元合作方，本系统主动跟随 SDK 演进（1.0→2.0 已平滑升级一次），可作为与智元深化合作的抓手——推动系统对接智元生态、共建桌面端能力，或作为合作交付方案的一部分 |
| 单人开发维护 | 代码全量文档化（架构/开发指南/铁律），AI 协作开发流程已验证高效（2.1.0 即此模式产出）；立项后可扩展人力 |

## 六、结论与申请

人形机器人正从"能走能说"进入"规模化落地"阶段，落地环节的**集群管理与编排能力**是交付的咽喉，也是当前厂商生态的明确空白。本项目以已验证的 2.1.0 系统为基础，申请立项并持续投入，将使公司：

1. **立即**获得多机交付的效率与专业度优势（装机/升级/编排全工具化）；
2. **短期**形成智能交互（对话/跟随/手势）的演示竞争力；
3. **中长期**沿数据采集与多型号扩展，构建机器人应用的开发平台能力。

### 合作推动（与智元）

公司作为智元合作方，本系统可作为**深化厂商合作的抓手**：

1. **技术对接**：系统严格基于智元 SDK 与设备能力构建（能力契约跟随 SDK 版本演进），随时可与智元技术团队建立对接沟通
2. **定位互补**：厂商生态当前聚焦机器人本体与单机体验，本系统补位**多机集群、交付运维、环境联动**的集成层——即使智元未来推出官方桌面端，本系统在集群编排/批量运维/物联网联动上的积累依然是合作共建的基础而非冲突
3. **合作形态可演进**：从"合作方自用工具"→"联合交付方案组件"→"共建/推荐方案"，随合作关系推进升级

**申请事项**：批准项目立项，纳入研发计划持续开发；后续视进展申请算力（语音/视觉模型）与人力支持，以及与智元方面的沟通协同。
