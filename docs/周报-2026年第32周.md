## 二、主要工作内容

### 1. 任务编排引擎升级（核心）— 支持并行组与分支块

本周最大改动。把任务编排从"线性步骤列表"升级为**支持并行组与条件分支的块式编排**。

- **后端数据模型 v2**：新增条件解析引擎（`task/cond.py`）、结构转换（`task/convert.py`）、并行执行调度（`task/engine.py`）、块校验（`task/validate.py`），共 +373 行。
- **编辑器 UI 重构**：改为左右布局（左链路展示 / 右配置区），并行组与分支块以可视化"块"形式编排，`TaskEditor.vue` 大改（+599 / -166）。
- **交互完善**：修复并行组内、分支泳道中步骤无法选中 / 删除 / 排序的问题。
- **历史兼容**：编排动作改用新动作组合后，历史任务自动归一化（`task/motions.py`），老任务无需手工迁移。

### 2. AI 智能生成编排任务（新功能）

接入 DeepSeek，用户用自然语言描述即可自动生成编排任务。

- Task 页新增"AI 生成"按钮，新建 `task/generate.py`（+201 行）。
- 升级生成能力以支持并行组 / 分支块，并采用动态 schema（+198 行）。
- **提示词工程优化**：提示词携带动作中文名、约束"同时"语义的语音 + 动作并行、修正动作 ID 错配；关闭 DeepSeek 思考模式，避免复杂提示词生成超时或失败。

### 3. 麦克风 VAD 采集 + 可插拔 ASR 语音识别（新功能）

新增完整的机器人语音输入链路（本周单次最大提交，11 文件 +561 行）。

- 新增 **Voice 页面**（+211 行），实时展示 VAD 语音段。
- 订阅 `/agent/process_audio_output` 获取降噪后 VAD 语音段（PCM 16k / 16bit / mono）。
- **ASR 可插拔框架**（`asr.py` +88 行）：通过 `robot.yaml` 切换 `none`（仅采集）/ `funasr`（识别），识别在独立线程运行，绝不阻塞 rclpy 回调。
- 新增 `routes/mic.py`（+104 行）与 node.py 内的 VAD 订阅逻辑（+118 行）。

### 4. 数据安全与部署改进

- **用户数据移出部署目录**：任务 / 项目 / 手机按键 / 媒体改存 `~/ggRobot-data/`，全量部署（`make clean/ship`）不再清空机器人上的存量数据。
- **YAML 解析器剥离行内注释**，修复 `publish_rate` 被读成字符串导致服务启动崩溃。

### 5. Bug 修复与体验优化

- 修复项目数据迁移时错误导入不存在的模块（`project.motions`）。
- 修复 step-card 因 `box-sizing` 与并行 / 分支块不等宽、导致普通步骤卡片溢出。
- 任务编辑器弹窗加宽、排版优化、保存提示由 `alert` 改为 message。
- 开发者模式区块调整到音量面板右侧空位。
