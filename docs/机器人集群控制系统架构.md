## 1. 系统定位

**多机器人通用管理与集群控制桌面平台**：一台 Mac/Windows 电脑管理局域网内多台人形机器人（X2，未来 A2/A3/机器狗），覆盖「装机接入 → 日常操控 → 多机编排 → 地图导航 → 数据管理 → 批量运维」全生命周期。

三端解耦，**能力契约**（`contracts/catalog.json`）是三端唯一真源——机器人有什么能力，由机器人自己上报，平台与界面零代码适配新型号。

## 3. 三端职责

### 3.1 机器人 Agent（`agents/x2/`，.deb 分发）

- **纯 API 化**：FastAPI(:8300) + rclpy 守护线程，REST 指令 + WS 数据流
- **命令队列模式**：HTTP 线程 → `queue.Queue` → rclpy 线程 spin 消费（rclpy 不能在 uvicorn 线程直接调用），Future 回传结果
- **会话锁**：同一时刻单一控制者（client_id 绑定 WS 心跳，他人 409/423，可接管）——多客户端互斥的安全基石
- **能力上报**：`/api/capabilities` 按契约目录上报（动作清单 YAML 化，机器人上改文件重启即生效）
- **双通道**：REST（指令，按需）+ WS v2（wildcard 订阅：传感器 200ms / 相机 JPEG 帧 100ms / 编排事件 / 建图激光点云 125ms）

### 3.2 平台 Sidecar（`platform/server/`，随客户端进程拉起）

- **单例复用**：8310-8330 探测 healthz，已运行同版本则复用（多窗口共享一个 DB）
- **职责**：设备登记（SN 唯一身份）+ 网段扫描发现 + hub 5s 聚合在线状态；**编排执行器**（分发→广播 start_ts→聚合轮询→三方步骤代发）；自由控制项/三方能力/编排 CRUD（SQLite）
- **本地语音转写**：内置 paraformer(82MB 装完即用) + 可下载 SenseVoice(230MB 高精档)，全离线
- 打包：PyInstaller onedir，随 dmg 的 extraResources 分发

### 3.3 桌面客户端（`platform/desktop/`）

- Electron + React + Semi Design（日/夜主题跟随系统）+ Zustand
- 自绘标题栏 + 多窗口体系：装机向导 / 编排编辑（剪映式轨道）/ 建图工作台（实时点云）/ 快捷遥控小窗，均单例
- 与机器人通信全部直连 agent（低延迟）；与平台数据走 sidecar localhost

## 4. 核心机制

### 4.1 能力契约（三端解耦的关键）

`contracts/catalog.json`（13 能力类型）→ `make contracts` 生成 TS/Py 双端代码。**新型号接入 = 新 agent 上报自己的清单，平台与界面零改动**。前端动作下拉、编排步骤类型、灵创清单全部动态拉取。

### 4.2 多机编排（时间戳锚定）

```
平台并发分发各机轨道 → 广播 start_ts = now+1.5s（绝对墙钟）
→ 各 agent 以 start_ts 为时间轴原点，本地按 at 到点触发
→ 误差只取决于局域网墙钟漂移（NTP 下 <100ms），与网络往返无关
```

编辑器为剪映式串行轨道（任务只能接续、拖拽排序），保存时自动计算 at；三方能力（HTTP 接口）注入为步骤类型、由平台按时间轴代发（机器人无需外网）。失败跳过继续、掉线 3 次判失败其余机继续、全局单 run 锁。

### 4.3 建图工作台（实时点云）

agent 仅建图中订阅激光 PointCloud2 → 降采样(≤2000 点 int16) → WS 二进制帧；客户端按帧内位姿做运动补偿，点云在世界坐标累积呈现（走到哪墙画到哪）+ 轨迹线，窗内遥控闭环（同 WS 收发）。

### 4.4 批量运维

SSH（sudoers 免密仅 `/usr/bin/apt`）→ 上传 deb → `apt install`（postinst 自动注册 user systemd）→ 版本核对。多机并发、失败保留旧版本（apt 原子性）、更新前机器人 TTS 播报。deb 版本号由 git describe 注入 `__version__`，更新核对同源可靠。

### 4.5 安全模型

- 机器人：Bearer token（每台独立，可轮换）+ SN 物理身份 + 会话锁单控制者
- 桌面：contextIsolation + 窄 IPC 面；sidecar 只绑 127.0.0.1
- 机器人侧铁律：远端只允许 apt（systemd/系统文件变更全部收在 deb 脚本内）

## 6. 技术栈与工程

| 端 | 栈 |
|---|---|
| 桌面 | Electron 33 / electron-vite / React 18 / Semi Design / Zustand / three.js |
| Sidecar | Python 3.12 / FastAPI / SQLModel(SQLite) / httpx / sherpa-onnx |
| Agent | Python 3.10+ / FastAPI / rclpy / ssh 部署链（dpkg-deb + apt） |

质量保障：`make test` 回归（agent 单测 24 + 端到端 21 项断言）；前端 tsc 全绿 + 实机验证清单；deb/dmg 双产物 CI 命令化（`make agent-deb` / `make desktop-package`）。

## 7. 演进方向

- **语音对话闭环**：ASR（已就绪）+ LLM API + TTS —— 语音指令驱动动作
- **自主移动**：定点导览（SDK 导航到点开放后）、巡逻安防
- **感知**：人体跟随、手势识别、物体识别（实验室已占位）
- **多型号**：A2/A3/机器狗 agent（能力契约保证零前端适配）
- **数据**：遥操作数据采集导出（对接开源训练生态）、数字孪生实时镜像
